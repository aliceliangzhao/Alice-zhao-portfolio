## Anti-Patterns Verdict

**Does this look AI-generated?** Not slop, but on a knife's edge.

**LLM assessment:** First-order reflex — if you asked "what does a designer portfolio look like," you'd get exactly this: black grotesk on white, 12-col grid, giant name, hairline-ruled project list. The *static* first paint is hard to distinguish from a thousand template Swiss portfolios. Second-order reflex — brand.md names "editorial-typographic / black-on-white-grid" as a currently-saturated lane, and the page escapes it on the strength of ONE asset: the halftone dot-morph. That morph is genuine craft (three quantized dot sizes, geometric merge, a dilating glyph clip-mask) — a technique a template generator does not produce. But the signature is load-bearing: it currently carries the entire originality budget alone, and only in motion. A visitor who lands during the 900ms solid hold sees only the genre.

**Deterministic scan:** detect.mjs returned ONE warning — `single-font` (only `var(--font-sans)` used, index.html:18). This is a **contextual false positive**: DESIGN.md's "One-Family Rule" makes Satoshi-carries-everything a deliberate, documented identity choice, and brand.md says identity-preservation wins for already-committed type. Not a real finding. No P0/P1 anti-patterns (no gradient text, no eyebrows, no card-grid clichés, no side-stripes) — the page is clean against the absolute bans.

**Visual overlays:** No live browser overlay — browser automation is unavailable in this environment. Assessment used the repo's real renders of this page (the desktop first-screen with grid overlay, the 3-project list, and a mid-morph hero frame) plus full source analysis and verified contrast math.

## Overall Impression

Competent and disciplined, with one real moment of brilliance that's left to chance. The morph is the gut-punch and it lands; everything around it is the genre default executed cleanly. The single biggest opportunity: **stage the peak and make the page a system with a signature, not a default page wearing one trick.** Right now the best asset is gambled on animation timing, the two acts a recruiter wants (Resume, Email) don't work, and the secondary text fails the page's own accessibility bar.

## What's Working

1. **The morph is real craft, not decoration.** Geometric dot-merge with three quantized sizes and a dilating glyph clip-mask (index.html:447–508). Letters appear because dots physically merge, not via a fade — it reads as engineering taste, not a filter. It earns its "one signature moment" budget.
2. **Token discipline + portability.** Every value lives in tokens.css; the JS reads animation params via `getComputedStyle` (index.html:345–349) so there's a single source of truth. Directly serves the "build it so it travels" principle — a coding agent can lift this cleanly into the real codebase.
3. **Accessibility architecture is structurally right.** A real visually-hidden `<h1>`, `role="img"` + `aria-label` on the canvas, and genuine `prefers-reduced-motion` paths for both the morph and the scroll cue (index.html:209–212). The contrast bug aside, the craft-as-accessibility intent is honored at the structural level.

## Priority Issues

**[P0] Muted text fails WCAG AA — and contradicts the design spec.**
- *Why it matters:* `tokens.css:12` ships `--color-muted: #9b9b9b` = **2.78:1** on white (verified), below AA's 4.5:1. It governs the intro's second clause ("Previously built design systems…") and all three project tag rows — content, not decoration. DESIGN.md §2 already mandates `#767676` (**4.54:1**, verified) and deprecates `#9b9b9b` by name. The docs are corrected; the token lags. This is a shipped bug, not identity.
- *Fix:* one line — `--color-muted: #767676;` in tokens.css:12.

**[P0] Every navigation and utility link is dead (`href="#"`).**
- *Why it matters:* the page's stated success condition is "pull toward the work." Work/About/Lab + LinkedIn/Email/Resume (index.html:258–266) all point to `#`. A hiring manager convinced in 5 seconds has nowhere to go — and Resume/Email are exactly what a recruiter reaches for.
- *Fix:* wire real destinations. At minimum: "Work" scrolls to the project list, "Email" is a `mailto:`, "Resume" is a real URL.

**[P1] The peak is un-staged — no first-load choreography.**
- *Why it matters:* the morph loops on a timer from frame 1, and the page otherwise appears instantly. Whether a visitor sees the signature is luck-of-the-cycle; landing during the solid hold = "static Swiss portfolio." The single best asset is gambled on timing, against the "reward a 5-second glance first" principle.
- *Fix:* trigger the morph as a one-shot dots→solid entrance on load (once, then settle into or retire the idle loop), so the signature is the first thing every visitor sees. Keep the reduced-motion static path unchanged.

**[P1] Longest project title competes with the hero register and wraps heavily.**
- *Why it matters:* project titles use `--font-size-h1: clamp(40px, 7vw, 96px)` — a hero-scale token. "AWS agentic experience: Let agents do the heavy lifting" already wraps to ~4 lines in a half-width column (unnamed.png), unbalanced against 2-line neighbors, and the 7vw mid-zone pushes it large in the narrowing single column at tablet/mobile. DESIGN.md's own Don't: "don't let large headings overflow their grid track at any breakpoint."
- *Fix:* give project titles their own slightly lower clamp ceiling (they needn't rival the hero) or tighten the vw coefficient; test this exact string at 640–900px.

**[P2] Scroll cue sits bottom-right, where the eye isn't.**
- *Why it matters:* `.scroll-cue` is `right: var(--space-pad)` (index.html:154). After the hero, the Western reading eye exits bottom-left, so the one wayfinding signal reads as decoration more than instruction.
- *Fix:* move to bottom-left or center, anchored under the hero's left edge where the gaze rests.

**[P2] The "pull toward the work" payoff is three empty gray boxes.**
- *Why it matters:* placeholders are intentional, but the arc peaks at the name and then delivers nothing visual for the work itself; impact claims ("0→1 in 8 weeks") have no visual backing. The page can't be judged "exceptional" until at least one real thumbnail exists — this critique's verdict is provisional on placeholders.
- *Fix:* out of scope now, but ship at least one real project image before calling the page done.

**Sam (screen reader + keyboard):**
- Passes: canvas `<h1>` + `aria-label`; reduced-motion paths; scroll cue correctly `aria-hidden`.
- Fails: muted intro clause + tags at 2.78:1 — low-vision users lose the employer history and all project tags. [P0]

## Minor Observations

## Questions to Consider
1. What if the morph were the page-LOAD event, not an idle loop? A single directed dots→solid entrance guarantees every visitor gets the gut-punch — and you could retire the perpetual loop (which risks reading as a restless GIF to a peer).
2. The signature is one word. What carries originality between the hero and the empty thumbs? Could the titles, hairlines, or meta rows borrow even a whisper of the halftone language so the page is a system with a signature, not a default page wearing one trick?
3. Is "black grotesk on white grid" the idea, or the absence of one? What single compositional decision — asymmetry, an off-grid intrusion, the name bleeding off the right edge — would make a peer say "I haven't seen that" about the static frame, not just the motion?
4. Where does a convinced visitor go? If success is the pull toward the work, why does the page end on three placeholders and dead links? What is the one deliberate exit gesture (a live Resume, one real project) that turns impression into momentum?

# Alice Zhao — UX Portfolio

The portfolio site of Alice (Liang) Zhao, a Senior UX Designer at Amazon, covering case studies in cloud infrastructure, AI-native product design, and design systems.

**Live site: [alicezhao.work](https://alicezhao.work)**

## About

A hand-built portfolio focused on scanability: a few scrolls on any page give a complete picture of who Alice is, what she has shipped, and the impact of her work. It features three in-depth case studies (AWS S3 Tables, Amazon Q assistant, and Simplifying Data Access), each with a sticky section nav, scroll-driven storytelling, and product visuals in a warm, editorial layout.

## Tech

- [Next.js](https://nextjs.org) (App Router), statically exported
- CSS only for styling and motion, no animation libraries
- Deployed to GitHub Pages via GitHub Actions on every push to `main`
